# Contributing

Thanks for helping.

## Reporting a problem

Open an issue and include your macOS or Windows version, your browser and its version, what you did, what you expected and what happened.
Don't include screenshots or log entries that show private tabs.

## Suggesting a change

For anything bigger than a small fix, open an issue first.

## Pull requests

- Keep each one to a single change.
- Run `node test.js`, plus `sh build.sh` for Mac changes or `windows\build.cmd` for Windows changes; they must succeed.
- Say which browsers you tried it in.
- Update the README if what people see or do changes.
- Nothing may send browsing data off the user's computer.
