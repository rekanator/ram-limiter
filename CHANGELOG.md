# Changes

## 2.1 update: Windows

- First Windows version: a tray app for 64-bit Windows 10 and 11, using the same extension.
- Also supports Opera GX (Windows only).
- Limit choices of 8, 10 and 12 GB (Mac and Windows).
- The menu stays open while you change settings (Mac and Windows).
- Mac: the Numbers icon shows 0/limit, greyed, when the limiter is off or paused, instead of words.
- Fixed (extension, Mac and Windows): with 10 or 20 second checks, checking could stop after the app was quit and reopened, until the extension was reloaded.

## 2.1

First public version.

- Memory limit from 2 to 6 GB, set separately for each browser.
- Works with Opera, Chrome, Edge, Brave and Vivaldi (see the README for which are tested).
- Unloads the tab you haven't viewed for the longest time.
- Protects pinned tabs, tabs playing sound, chosen sites, unsaved text, calls and uploads.
- Nap Chip logo, also the default menu bar icon.
- Menu bar icons that turn yellow, orange and red near the limit.
- Pause, grace period, unload log and Memory Freed Today.
